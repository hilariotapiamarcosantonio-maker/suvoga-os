# SuVoGa OS Interface System

## Direction
SuVoGa OS is a holistic, premium, clean and organic school interface for massage and spa training. Public screens should feel like an elegant wellness school, not a delivery, route, sales, collections or commission tool.

## Palette
- Backgrounds: white, `#FDFBF7`, `#FAFAFA`
- Primary text and actions: forest green `#0D3B22`
- Luxury accent: soft gold `#D4AF37`
- Supporting text: muted botanical neutrals such as `#4E6658`, `#6B6048`, `#8A7D69`
- Never use black or dark-mode app shells for SuVoGa screens.

## Typography
- Headings use the serif utility `suvoga-serif`.
- CRM tables, forms, descriptions and controls use the clean sans utility `suvoga-sans`.

## Components
- Public `/`: only the school hero and course catalog.
- Private `/admin`: only SuVoGa inscription management, pending-inscription summary and WhatsApp contact actions.
- Cards and panels use `rounded-2xl`, fine gold borders and `shadow-sm`; hover may move to `hover:shadow-md`.
- Inputs use thin outlines or bottom borders with forest-green focus states.
- Primary buttons use `bg-[#0D3B22]` with white or ivory text.

## What To Avoid
- No inherited operations shell, role navigation, route dashboards, sales metrics, collection flows, daily targets, delivery panels or commission interfaces.
